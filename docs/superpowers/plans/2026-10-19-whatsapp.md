# GeoAI no WhatsApp (Evolution API) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ligar o WhatsApp de cada usuário ao GeoAI pela Evolution API: assistente com sugestões confirmadas por "1/2" e lembretes nos mesmos crons do Telegram, num número pessoal (silêncio com contatos não ligados e grupos).

**Architecture:** Peças puras do WhatsApp em `lib/whatsapp.ts`. A rodada do assistente e a resolução de escolhas saem da rota do Telegram para `lib/chat-turn.ts` e `lib/chat-actions.ts`, usados pelos dois canais. Ligações em tabelas próprias (`whatsapp_links`, `whatsapp_codes`). O webhook `/api/whatsapp` responde 200 na hora e processa com `after()`. As funções de lembrete agrupam as conversas por usuário.

**Tech Stack:** Next.js 16 (App Router, `after` de `next/server`), TypeScript, Drizzle/Postgres, AI SDK 7, Evolution API v2.3.7, testes com `node --experimental-strip-types --test`.

**Spec:** `docs/superpowers/specs/2026-10-19-whatsapp-design.md`

## Global Constraints

- Textos em português do Brasil. Toda mensagem do bot no WhatsApp começa com `🤖 `, inclusive cada parte de uma mensagem quebrada.
- Variáveis: `EVOLUTION_API_URL`, `EVOLUTION_API_KEY`, `EVOLUTION_INSTANCE`. Nenhuma chave no repositório. Sem as três, o WhatsApp fica "Não configurado".
- Toda chamada à Evolution leva os cabeçalhos `apikey` e `ngrok-skip-browser-warning: true`, com tempo máximo de 15 s.
- Segredo do webhook: SHA-256 hex de `'geoai-whatsapp:'+EVOLUTION_API_KEY`, no cabeçalho `x-geoai-secret`.
- Regras do número pessoal (spec, "Regras do bot"): grupos e listas fora; `fromMe` só na conversa consigo mesmo (`remoteJid === ownerJid`); textos que começam com `🤖` fora; repetidos fora; conversa não ligada só reage a `GEOAI <código>`.
- Código de ligação: 6 caracteres de `ABCDEFGHJKMNPQRSTUVWXYZ23456789`, 15 minutos, uso único.
- Módulos importados pelos testes (`lib/whatsapp.ts`, `lib/chat-actions.ts`, `lib/reminder-channels.ts`, `lib/trt-reminders.ts`, `lib/female-reminders.ts`) importam módulos de `lib/` com `.ts`, sem `@/`, sem enums e sem propriedades de parâmetro.
- O comportamento do Telegram não muda (a refatoração da Tarefa 2 é só de organização). Os testes atuais continuam passando.
- ESLint: arquivos novos sem erros; os alterados não passam da linha de base, que a Tarefa 1 mede e registra no relatório. `npm run lint` no repositório inteiro não serve de critério.
- Linha de base em `feat/whatsapp` (780c7a5) depois de `npm ci`: `npm test` 159/159, `npm run typecheck` 0.

## Review Focus

- **Eco do bot:** uma resposta longa quebrada em partes, em que só a primeira teria o 🤖, faria o bot responder a si mesmo na conversa consigo mesmo. Toda parte precisa do prefixo (teste na Tarefa 1).
- **Mensagem do dono para um amigo** (`fromMe`, `remoteJid` do amigo): ignorada sem consulta ao banco (teste na Tarefa 1).
- **A Evolution reenvia o mesmo evento** (timeout ou falha): o `key.id` repetido não gera segunda resposta. O claim acontece antes da IA, e o webhook responde 200 na hora, com o trabalho em `after()`.
- **Usuário com Telegram e WhatsApp:** recebe o lembrete nos dois e é marcado uma vez. Uma falha no WhatsApp (ngrok fora) não impede o Telegram e vice-versa (teste na Tarefa 4).
- **"1" sem opções pendentes:** vai para o assistente como texto, sem erro (comportamento na Tarefa 3).

import {chunkText} from './telegram.ts';
// Peças puras do GeoAI no WhatsApp (Evolution API): leitura dos eventos com as regras do número pessoal, código de ligação,
// opções "1/2" no lugar dos botões do Telegram e o cliente HTTP da Evolution.
export const BOT_PREFIX='🤖 ';
export const WA_LIMIT=4000;
export const CODE_ALPHABET='ABCDEFGHJKMNPQRSTUVWXYZ23456789';
export type WaMessage={id:string;jid:string;fromMe:boolean;text:string;label:string;textless:boolean};
type RawKey={id?:unknown;remoteJid?:unknown;fromMe?:unknown;participant?:unknown};
type RawEvent={event?:unknown;instance?:unknown;data?:{key?:RawKey;pushName?:unknown;message?:Record<string,unknown>|null}};
const isGroup=(jid:string)=>/@(g\.us|broadcast|newsletter)$/.test(jid);
function textOf(m:Record<string,unknown>|null|undefined){if(!m)return '';if(typeof m.conversation==='string')return m.conversation;const e=m.extendedTextMessage as {text?:unknown}|undefined;return typeof e?.text==='string'?e.text:'';}
// Número pessoal: grupos e listas ficam de fora; mensagens do dono só valem na conversa consigo mesmo; o que o bot escreveu (🤖) é ignorado.
export function parseEvolutionEvent(raw:unknown,instance:string,ownerJid:string):WaMessage|null{
 const e=raw as RawEvent|null;if(!e||typeof e!=='object'||e.event!=='messages.upsert'||e.instance!==instance)return null;
 const k=e.data?.key;if(!k||typeof k.id!=='string'||!k.id||typeof k.remoteJid!=='string'||!k.remoteJid)return null;
 const jid=k.remoteJid,fromMe=k.fromMe===true;if(isGroup(jid)||k.participant||(fromMe&&jid!==ownerJid))return null;
 const text=textOf(e.data?.message).slice(0,4000);if(text.trimStart().startsWith('🤖'))return null;
 const name=typeof e.data?.pushName==='string'?e.data.pushName.trim():'';
 return {id:k.id.slice(0,128),jid,fromMe,text,label:((name?name+' · ':'')+'+'+jid.split('@')[0]).slice(0,120),textless:!text.trim()};}
export function linkCodeOf(text:string){const m=/^\s*geoai\s+([a-z0-9]{6})\s*$/i.exec(text);return m?m[1].toUpperCase():null;}
export function newLinkCode(random:(n:number)=>Uint8Array=n=>crypto.getRandomValues(new Uint8Array(n))){return [...random(6)].map(b=>CODE_ALPHABET[b%CODE_ALPHABET.length]).join('');}
export function waCommand(text:string):'ajuda'|'desconectar'|null{const m=/^\s*\/?(ajuda|help|desconectar)\s*$/i.exec(text);if(!m)return null;return m[1].toLowerCase()==='desconectar'?'desconectar':'ajuda';}
export const waLink=(ownerJid:string,code:string)=>'https://wa.me/'+ownerJid.split('@')[0]+'?text='+encodeURIComponent('GEOAI '+code);
export function displayNumber(ownerJid:string){const d=ownerJid.split('@')[0];return d.startsWith('55')&&d.length>=12?'+55 '+d.slice(2,4)+' '+d.slice(4,-4)+'-'+d.slice(-4):'+'+d;}
export type Button={text:string;callback_data:string};
// Os botões do Telegram viram opções numeradas; a ligação guarda as escolhas para a resposta "1" ou "2".
export function choicesFrom(markup:{inline_keyboard:Button[][]}){const buttons=markup.inline_keyboard.flat().slice(0,9);return {choices:buttons.map(b=>b.callback_data),text:'Responda '+buttons.map((b,i)=>(i+1)+' para '+b.text).join(' · ')};}
export function choiceIndex(text:string){const m=/^\s*([1-9])\s*$/.exec(text);return m?Number(m[1])-1:null;}
// Toda parte começa com o prefixo: uma parte sem ele, na conversa consigo mesmo, seria lida como mensagem do dono.
export const waChunks=(text:string)=>chunkText(text,WA_LIMIT-BOT_PREFIX.length).map(p=>BOT_PREFIX+p);
export async function waSecret(apiKey:string){const hash=await crypto.subtle.digest('SHA-256',new TextEncoder().encode('geoai-whatsapp:'+apiKey));return [...new Uint8Array(hash)].map(b=>b.toString(16).padStart(2,'0')).join('');}
export type EvolutionConfig={url:string;key:string;instance:string};
export function evolutionConfig(env:Record<string,string|undefined>):EvolutionConfig|null{const url=env.EVOLUTION_API_URL?.trim().replace(/\/+$/,''),key=env.EVOLUTION_API_KEY?.trim(),instance=env.EVOLUTION_INSTANCE?.trim();return url&&key&&instance?{url,key,instance}:null;}
type Fetch=(url:string,init:RequestInit)=>Promise<Response>;
export function evolutionApi(c:EvolutionConfig,fetcher:Fetch=(url,init)=>fetch(url,init)){
 async function call<T>(method:'GET'|'POST',path:string,body?:unknown):Promise<T>{
  const r=await fetcher(c.url+path,{method,headers:{apikey:c.key,'ngrok-skip-browser-warning':'true',...(body===undefined?{}:{'content-type':'application/json'})},...(body===undefined?{}:{body:JSON.stringify(body)}),signal:AbortSignal.timeout(15000)});
  if(!r.ok)throw new Error('Evolution respondeu '+r.status);return await r.json().catch(()=>null) as T;}
 const inst=encodeURIComponent(c.instance);
 return {
  sendText:(jid:string,text:string)=>call('POST','/message/sendText/'+inst,{number:jid,text}),
  setWebhook:(url:string,secret:string)=>call('POST','/webhook/set/'+inst,{webhook:{enabled:true,url,events:['MESSAGES_UPSERT'],byEvents:false,base64:false,headers:{'x-geoai-secret':secret}}}),
  async ownerJid(){const list=await call<{name?:string;ownerJid?:string}[]|null>('GET','/instance/fetchInstances?instanceName='+inst);const jid=Array.isArray(list)?list.find(x=>x.name===c.instance)?.ownerJid:undefined;if(!jid)throw new Error('Instância não encontrada');return jid;}};}

// Uma escolha (botão do Telegram ou resposta "1/2" do WhatsApp) resolvida sem efeitos: quem chama grava o comando e envia a resposta.
export type ChoiceResult={command?:Command;reply:string;ack:string;pending?:Pending;expired?:true};
const EXPIRED='Essas sugestões não estão mais disponíveis.';
export function resolveChoice(data:string,state:Workspace,pending:Pending,now?:Date):ChoiceResult{
